# NorthStar Enterprise Cloud Security Evidence

This directory contains sanitized implementation evidence supporting the NorthStar enterprise cloud security architecture, security controls, governance decisions, and validation activities.

Sensitive identifiers, credentials, tokens, personal information, subscription IDs, and tenant IDs are excluded from public evidence.

Start with the [NorthStar Portfolio Evidence Index](portfolio-evidence-index.md) for a recruiter-oriented map from portfolio claims to supporting repositories and files.
